Upload photos here (JPG/PNG/WEBP) to have them located: on GitHub, open this folder,
click **Add file → Upload files**, and commit. The **Locate photos** workflow runs and puts
a table of guessed locations (with map links and the signs it read) on its summary page.

The guess ignores GPS stored in the photo; if the photo has GPS, the table also shows how far
off the guess was, so phone photos make a good test.

**Photos uploaded here are public if the repository is public, including the GPS location
stored in them.** Don't upload photos of your home or anything private.
